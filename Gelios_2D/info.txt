# Документация проекта Gelios_2D
Документация сгенерирована автоматически с помощью Copilot на основе комментариев в коде.

## Общее описание
Gelios_2D - это программный комплекс для моделирования газодинамических и плазменных процессов 
с использованием методов Монте-Карло и схем конечных объемов. Проект предназначен для решения задач астрофизики, 
в частности, моделирования взаимодействия солнечного ветра с межзвездной средой.

## Структура проекта

### Основные файлы:
- **Gelios_2D.cpp** - главный файл с функцией main()
- **Help.h** - заголовочный файл с константами, макросами и вспомогательными функциями
- **Setka.h/cpp** - класс для работы с сеткой (745KB кода!)
- **MKmethod.h/cpp** - класс методов Монте-Карло
- **Solvers.h/cpp** - численные решатели (HLLC, TVD схемы)
- **sensor.h/cpp, sensor2.h/cpp** - классы для датчиков частиц
- **Point.h/cpp, Cell.h, Gran.h** - базовые геометрические элементы
- **Rail.h/cpp** - класс лучей для управления сеткой
- **Interpol_Setka.h/cpp** - интерполяционная сетка
- **Dist_func.h** - функции распределения

## Основная функциональность

### 1. Параметры задачи (Help.h)
```cpp
#define parameter_1 "vers17_11.txt"         // Файл загрузки сетки
#define parameter_21 "vers17_11.txt"        // Файл газодинамических параметров  
#define parameter_22 "source_vers17_12.txt" // Файл источников Монте-Карло
#define parameter_4 false                   // Режим: false=МК, true=газодинамика
#define Kn_ 0.01                           // Число Кнудсена
#define RR_ 390.222                        // Характерный размер задачи
```

### 2. Типы расчетов
- **Газодинамический режим** (parameter_4 = true): решение уравнений Эйлера
- **Режим Монте-Карло** (parameter_4 = false): кинетическое моделирование
- **Гибридный режим**: комбинация обоих методов

### 3. Структура сетки (класс Setka)
```cpp
vector <Point*> All_Points;      // Все узлы сетки
vector <Cell*> All_Cells;        // Все ячейки
vector <Gran*> All_Gran;         // Все грани
vector <Rail*> A_Rails, B_Rails; // Лучи сетки
```

### 4. Геометрические зоны
- **R1_** = 1.0/RR_ - внутренний радиус
- **R11_** = 38.0/RR_ - граница внутренней области  
- **R111_** = 50.0/RR_ - граница расширенной внутренней области
- **R2_** = 100.0/RR_ - промежуточный радиус
- **Rmax_** = 2.2 - максимальный радиус для МК

## Основные методы

### Класс Setka - главный класс проекта:

#### Создание и загрузка сетки:
- `Setka(N1,N2,N3,N4,M1,M2,M3,M4)` - конструктор с размерами
- `Download_Setka_ALL_ALPHA_2_0(filename)` - загрузка сетки из файла
- `Save_Setka_ALL_ALPHA(filename)` - сохранение сетки

#### Газодинамические методы:
- `Go_stationary_5_komponent_inner_MK(steps)` - стационарный расчет внутренней области
- `Go_5_komponent_MK(steps, move_grid)` - нестационарный расчет с МК источниками
- `HLLC_2d_Korolkov_b_s(...)` - решатель HLLC для 2D задач

#### Методы Монте-Карло:
- `MK_start_2_0()` - запуск моделирования Монте-Карло
- `Fly_exchenge_Imit_Korol(...)` - трассировка частиц
- `Download_Source_MK(filename)` - загрузка МК источников
- `Save_Source_MK(filename)` - сохранение МК источников

#### Вывод результатов:
- `Print_Tecplot_MK(name)` - вывод в формате Tecplot
- `Print_Tecplot_MK_2d(name)` - 2D вывод в Tecplot
- `Print_Gran(filename)` - вывод граней
- `Print_cell2(filename)` - вывод ячеек

### Класс MKmethod - методы Монте-Карло:
- `Change_Velosity4(...)` - изменение скорости частиц при столкновениях
- `Init_Parametrs(...)` - инициализация параметров частиц
- Интегральные функции: `int_1()`, `int_2()`, `int_3()`

## Физические модели

### 1. Многокомпонентная плазма (5 компонент):
- Протоны солнечного ветра
- Нейтральный водород межзвездной среды  
- Пикап-ионы (4 популяции: H1, H2, H3, H4)

### 2. Численные схемы:
- **HLLC** - решатель Римана для гиперболических уравнений
- **TVD** - схемы с ограничением вариации  
- **Монте-Карло** - кинетическое моделирование столкновений

### 3. Граничные условия:
- Сферические границы (Inner, Contact, Outer)
- Подвижная сетка для отслеживания ударных волн

## Управляющие параметры в main():

### Основные блоки выполнения:
```cpp
if (parameter_4) {
    // Газодинамический расчет
    SS->Go_stationary_5_komponent_inner_MK(300);
    SS->Go_5_komponent_MK(1500);
} else {
    // Расчет Монте-Карло  
    SS->MK_start_2_0();
}
```

### Настройка схем счета:
- Выбор метода HLLC для контактных разрывов
- Управление движением сетки
- Нормировка параметров между режимами

## Компиляция и запуск

### Требования:
- C++14 или выше
- OpenMP для параллелизации
- Опционально: MPI (если USEMPI = true)

### Основные макросы препроцессора:
- `USEMPI` - использование MPI
- `pop_atom 4` - количество популяций атомов
- Геометрические константы (R1_, R2_, etc.)

## Советы по использованию

### 1. Для газодинамического расчета:
- Установить `parameter_4 = true`
- Загрузить начальные условия через `Download_Setka_ALL_ALPHA_2_0()`
- Использовать циклы с `Go_stationary_5_komponent_inner_MK()` и `Go_5_komponent_MK()`

### 2. Для Монте-Карло:
- Установить `parameter_4 = false`  
- Подготовить источники через `Download_Source_MK()`
- Запустить `MK_start_2_0()`

### 3. Для отладки:
- Использовать `Print_Tecplot_MK()` для визуализации
- Проверять сетку через `Proverka()` и `Print_Gran()`
- Контролировать параметры через вывод в консоль

### 4. Оптимизация производительности:
- Настроить количество шагов в циклах расчета
- Использовать параллельные версии методов
- Контролировать частоту вывода результатов

## Типичная последовательность работы:
1. Создание объекта `Setka* SS = new Setka()`
2. Загрузка данных `SS->Download_Setka_ALL_ALPHA_2_0(parameter_1)`
3. Подготовка `SS->TVD_prepare()` и `SS->Proverka()`
4. Выбор режима расчета (ГД или МК)
5. Основной цикл расчета
6. Сохранение результатов

Проект представляет собой мощный инструмент для численного моделирования сложных газодинамических 
и кинетических процессов в астрофизических приложениях.
